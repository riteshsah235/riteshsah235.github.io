# Portfolio

Personal portfolio of Ritesh Sah, an AI/ML Engineer studying Data Science & Applications at IIT Madras.

Live site: https://riteshsah235.github.io

Plain HTML, CSS and JavaScript. No build step.

- **Works:** live project demos only.
- **Tech Stack:** filterable chips.
- **GitHub Activity:** the yearly contribution heatmap loads from the public GitHub contributions of `riteshsah235` each time the page opens. If the feed is down, it shows the saved snapshot in `contrib.json`.
- **Contact:** GitHub, LinkedIn, Kaggle, mail, X, Instagram. The resume tile is a placeholder until the file is added.

Design follows the structure of rmoon.me: dark page, particle moon hero, card grid and floating pill navigation. All content and code are original.
